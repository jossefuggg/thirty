Every complaint, on the clock.

Thirty reads each medical device complaint the minute it arrives, scores it, decides what the FDA must be told under 21 CFR 803, and drafts the Form 3500A. A named person reviews, approves and files. Thirty drafts; a human files.

Which agent should draft?

The agent classifies each complaint and drafts the report. You can switch agents or install plugins later under Settings → Plugins.

What the local model needs
  • An OpenAI-compatible server on this machine or your network: http://localhost:11434/v1 (Ollama, easiest on a laptop), http://localhost:8080/v1 (llama.cpp), http://localhost:8000/v1 (vLLM on a GPU server).
  • A model that follows JSON instructions well. On a laptop (16 GB RAM, Apple Silicon or a recent CPU): an 8B-class instruct model, about 5 GB. On a GPU workstation: 30B-class gives better reasoning.
  • About 2 model calls per complaint (classification and the Form 3500A draft): 5–60 s on a laptop, 1–10 s on a GPU. Complaints queue; nothing is lost while it works.
